1. Які дані ми збираємо

Бот RentAlert збирає та зберігає такі дані про користувача:

  • Telegram chat ID — для надсилання сповіщень
  • Ім'я та username (якщо вказані в Telegram) — для персоналізації
  • Вибрані міста — для відстеження оголошень
  • Обрана країна та мова — для роботи інтерфейсу
  • Обране — список збережених оголошень
  • Лог дій — для покращення сервісу (додавання міст, оцінки)

2. Де зберігаються дані

Усі дані зберігаються в захищеній базі даних Turso. Доступ має лише власник бота.

3. Як ми використовуємо дані

  • Надсилання сповіщень про нові оголошення
  • Збереження налаштувань (міста, країна, мова)
  • Аналіз роботи бота (без персональних даних)

4. Передача третім особам

Ми не передаємо ваші дані третім особам. Єдине виключення — технічні сервіси:

  • Telegram — для доставки повідомлень
  • Turso — для зберігання бази даних
  • Render — хостинг сервера

5. Оголошення

Бот не є власником оголошень. Він агрегує публічну інформацію з відкритих джерел: OLX, DIM.RIA, Kleinanzeigen, Habitaclia, Njuškalo. Усі права належать відповідним сайтам.

6. Ваші права

Ви можете:

  • Видалити всі свої дані — команда /clear або видалення бота з Telegram
  • Дізнатися, які дані зберігаються — напишіть адміністратору
  • Відкликати згоду — просто видаліть бота

7. Cookies та трекінг

Бот не використовує cookies, не відстежує місцезнаходження, не має доступу до ваших контактів чи інших чатів.

8. Діти

Бот не призначений для осіб молодше 16 років. Ми свідомо не збираємо дані дітей.

9. Зміни політики

Ми можемо оновлювати цю політику. Актуальна версія завжди за посиланням, вказаним у боті.

10. Контакти

Питання та скарги — через бота (кнопка ❓ Довідка → 💬 Зворотний зв'язок) або @rentalert_v2_bot.

1. Data We Collect

RentAlert bot collects and stores:

  • Telegram chat ID — to send notifications
  • Name and username (if provided) — for personalization
  • Selected cities — for tracking listings
  • Country and language preferences — for the interface
  • Favorites — saved listings
  • Activity log — to improve the service

2. Where Data Is Stored

All data is stored in a secure Turso database. Only the bot owner has access.

3. How We Use Data

  • Sending new listing notifications
  • Saving preferences (cities, country, language)
  • Analyzing bot performance (no personal data)

4. Third Parties

We do not share your data with third parties. Technical services only:

  • Telegram — for message delivery
  • Turso — for database storage
  • Render — for server hosting

5. Listings

The bot does not own the listings. It aggregates public information from open sources: OLX, DIM.RIA, Kleinanzeigen, Habitaclia, Njuškalo. All rights belong to the respective websites.

6. Your Rights

  • Delete your data — command /clear or remove the bot
  • Know what data is stored — contact the admin
  • Revoke consent — just remove the bot

7. Cookies and Tracking

The bot uses no cookies, no location tracking, and has no access to your contacts or other chats.

8. Children

The bot is not intended for users under 16. We do not knowingly collect data from children.

9. Policy Changes

We may update this policy. The current version is always available at the link provided in the bot.

10. Contact

Questions and complaints — via the bot (❓ Help → 💬 Feedback button) or @rentalert_v2_bot.
